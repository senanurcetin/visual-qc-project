Steel QC knowledge assistant

A retrieval-augmented assistant over a steel quality-engineering knowledge base. Each passage is a point below. Pick a question to see which passages the system actually read before answering, and how much of the answer those passages support.

How it works

  1. 1
    Chunk

    Knowledge-base articles are split into short, section-aware passages.

  2. 2
    Embed

    An embedding model turns each passage into a vector; passages with similar meaning land close together. The vectors live in a Chroma vector database.

  3. 3
    Retrieve & answer

    The question is embedded the same way, the nearest passages are retrieved, and a language model answers from them with citations.
